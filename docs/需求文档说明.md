# 阿里云盘命令行 DeepSeek Harness 插件 — 需求文档说明

## 1. 项目定位
把 `aliyunpan`（tickstep/aliyunpan）命令行工具封装为 DeepSeek Harness 插件，为 Agent 提供阿里云盘文件管理、传输、分享、相册与同步能力。

## 2. 用户角色
| 角色 | 说明 |
| --- | --- |
| 终端用户 | 在 DSH Web UI 中管理阿里云盘 |
| Agent/模型 | 通过工具 schema 调用 aliyunpan 命令 |
| 开发者 | 配置 CLI 路径、配置目录、同步策略 |

## 3. 功能需求
### FR-1 账号
- FR-1.1 提供登录状态查询工具（`who`、`loglist`）。
- FR-1.2 提供登录引导工具（`login`，浏览器登录，5 分钟有效）。

### FR-2 网盘与目录
- FR-2.1 提供网盘切换工具（`drive`）与配额工具（`quota`）。
- FR-2.2 提供工作目录工具（`pwd`、`cd`）。
- FR-2.3 提供目录列表工具（`ls`/`ll`），支持 `-driveId`。

### FR-3 文件管理
- FR-3.1 提供创建目录（`mkdir`）、移动（`mv`）、重命名（`rename`）工具。
- FR-3.2 提供删除工具（`rm`），默认需要确认。
- FR-3.3 提供回收站工具（`recycle`）。

### FR-4 传输
- FR-4.1 提供上传工具（`upload`）：多文件/目录、排除正则、并发、秒传、UI 进度。
- FR-4.2 提供下载工具（`download`）：断点续传、并行、重试、校验、多用户联合下载、UI 进度。
- FR-4.3 传输任务参数可配置。

### FR-5 分享
- FR-5.1 提供设置分享、快传链接、列出已分享、取消分享工具。

### FR-6 相册
- FR-6.1 提供相簿列表、相簿详情、批量下载工具。

### FR-7 同步
- FR-7.1 提供同步启动/停止/列表工具。
- FR-7.2 支持 `upload`/`download` 模式与 `exclusive`/`increment` 策略。

## 4. 非功能需求
| 编号 | 需求 |
| --- | --- |
| NFR-1 | 全程 TDD，测试先行。 |
| NFR-2 | 所有工具返回结构化 JSON；进度类工具支持任务 ID 轮询。 |
| NFR-3 | 删除/覆盖类操作默认确认。 |
| NFR-4 | CLI 路径可配置（`aliyunpanBin`），配置目录可配置。 |
| NFR-5 | 登录态不进入仓库、日志、模型上下文。 |
| NFR-6 | 超时默认 60s（上传/下载可更长），可配置。 |
| NFR-7 | 支持无交互直接执行模式，适配 Agent 调用。 |

## 5. 用户交互逻辑
1. 首次使用：安装插件 → 配置 CLI 路径 → 检查 `who` → 未登录引导 `login` 浏览器授权。
2. 目录浏览：`ls` → UI 文件表格 → 点击进入目录。
3. 传输：选择本地/云端路径 → 工具调用 → UI 进度面板 → 完成/失败统计。
4. 删除/覆盖：UI 二次确认。
5. 同步：填写本地目录/云端目录/模式/策略 → 启动 → 展示同步任务状态。

## 6. 数据交互面板清单
| 面板 | 数据来源 | 主要字段 |
| --- | --- | --- |
| 账号面板 | who/loglist | 昵称、uid、登录设备 |
| 网盘面板 | drive/quota | 备份盘/资源库、总量/已用 |
| 文件列表面板 | ls/ll | 文件名、大小、修改时间、类型 |
| 路径栏 | pwd/cd | 当前工作目录 |
| 上传面板 | upload | 本地路径、云端路径、进度、并发、排除规则 |
| 下载面板 | download | 云端路径、保存目录、进度、重试、校验 |
| 分享面板 | share | 分享链接、密码、有效期、已分享列表 |
| 相册面板 | album | 相簿列表、照片列表、下载进度 |
| 同步面板 | sync | 本地目录、云端目录、模式、策略、任务状态 |
| 确认对话框 | rm/download --ow | 操作对象、确认参数 |
| 进度面板 | upload/download -ui | 总进度、单文件进度、速度、失败数 |
| 原始 JSON 开关 | 所有工具 | JSON 输出 |

## 7. 验收标准
- 每个 FR 至少一条自动化测试。
- 删除/覆盖 confirm=false 时拒绝执行。
- 未登录时返回明确错误与登录引导。
- `dsh plugin add` 安装成功。
- 中英文 README 开头互相引用。
