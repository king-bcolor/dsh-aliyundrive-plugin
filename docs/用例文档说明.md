# 阿里云盘命令行插件用例文档说明

## 1. 文档目的
本文档沉淀 `aliyunpan` 命令行工具的功能、命令示例、用例说明与参数限制，作为 DeepSeek Harness 插件设计依据。完整用例目录见 `docs/用例目录/README.md`。

## 2. 功能总览
- 账号：登录、账号列表、当前账号、切换账号、退出。
- 网盘：切换备份盘/资源库、配额、工作目录。
- 文件：ls/cd/pwd/mkdir/mv/rename/rm/recycle。
- 传输：上传、下载，支持并发、断点续传、秒传、UI 进度、排除正则。
- 分享：设置/列出/取消分享、快传链接。
- 相册：共享相簿列表、查看、批量下载。
- 同步：upload/download 两种模式，exclusive/increment 两种策略。
- 扩展：JavaScript 插件、config set、debug。

## 3. 用例分层
| 层级 | 用例 | 前置条件 |
| --- | --- | --- |
| L0 无登录 | help、version、config set | 安装 aliyunpan |
| L1 只读 | loglist/who/quota/ls/pwd/album list | 登录 |
| L2 文件写 | mkdir/mv/rename/rm/recycle | 登录 + 写权限 |
| L3 传输 | upload/download | 登录 + 写/读权限 |
| L4 分享与同步 | share/sync | 登录 + 对应权限 |

## 4. 输出契约
- 交互模式输出终端表格与进度条；`-ui` 显示 TUI 面板。
- 大部分命令支持直接执行，便于 Agent 调用。
- 错误：未登录、路径不存在、权限不足、下载链接失效等。

## 5. 典型用户故事
1. 作为用户，我想登录并查看账号信息。
2. 作为用户，我想列出并切换工作目录。
3. 作为用户，我想上传/下载文件并查看进度。
4. 作为用户，我想管理云盘文件（建目录、移动、重命名、删除）。
5. 作为用户，我想分享文件并管理分享链接。
6. 作为用户，我想把本地目录增量备份到云盘。
7. 作为 Agent，我想按结构化方式执行云盘文件操作。
