## 1. DeepSeek Harness 插件机制
- Host Cordis 插件：`name` / `inject = ['tools']` / `apply(ctx, config)`。
- Web client：`package.json.dsh.client` + `exports["./client"]`，浏览器侧注册 `ctx.slots`。
- 工具注册：`ctx.tools.register(defineTool({...}))`。
- `@deepseek-ai/dsh-tools` 在 DSH profile 中作为 peer 可用；本地无该依赖时 `src/define-tool.js` 提供同形 fallback，并编译出 registry-ready JSON Schema。
- 配置：profile 的 `cordis.patch.yml` 行内 `config` 直接传入 `apply`，由 `normalizeConfig` 校验并填默认值。
- 发布：npm 包 + `dsh.bundle.patch` + `cordis.patch.yml`。

## 3. 架构
```
Agent → tools.execute(name, args)
      → command-builder（参数校验 + argv 映射）
      → 短命令：runAliyunpan → classifyResult → JSON 结果
      → 长命令：startAliyunpan 后台运行 → task-manager 记录 handle
        → 返回 taskId → aliyunpan_task_status 读取 live snapshot
        → 进程结束后 classifyResult 并写入最终结果
Web UI → fetch /api/aliyundrive/* → HTTP API → 上述同一批工具/任务
      → conversation.view 注册「阿里云盘」标签页 → 动态表单渲染 25 个工具
```

## 4. 配置设计（实际默认值）
```js
const DEFAULT_CONFIG = Object.freeze({
  aliyunpanBin: 'aliyunpan',       // CLI 可执行文件或绝对路径
  configDir: undefined,            // 对应 ALIYUNPAN_CONFIG_DIR
  timeoutMs: 60000,                // 普通命令超时
  longRunningTimeoutMs: 3600000,   // 上传/下载/同步超时
  maxOutputBytes: 1024 * 1024,     // 单流输出截断上限
  confirmDangerous: true,          // 删除/覆盖/排他同步必须 confirm: true
})
```

## 6. 核心实现要点
### 6.1 runner
- `spawn(aliyunpanBin, args)`，参数数组传递，不做 shell 拼接。
- 短命令使用 `runAliyunpan` 等待退出；上传/下载/同步使用 `startAliyunpan` 后台运行并返回可轮询 handle。
- 超时：普通命令 `timeoutMs`；长任务 `longRunningTimeoutMs`；超时发送 SIGTERM。
- stdout/stderr 各受 `maxOutputBytes` 截断保护。

### 6.2 安全
- `rm`、`upload --ow`、`download --ow`、`album download-file --ow`、`sync start --policy exclusive` 要求 `confirm: true`（`confirmDangerous: false` 时可关闭）。
- 不读取登录态文件内容，只传递 `ALIYUNPAN_CONFIG_DIR` 环境变量。
- 路径参数禁止空路径、`-` 开头及 `|`、`;`、`&`、`$`、反引号、换行等字符；exn 正则只禁止控制字符。

### 6.3 Web UI
- `package.json.dsh.client` 声明 web client，`exports["./client"]` 指向 `lib/client.js`。
- 客户端在 `conversation.view` 注册 `aliyundrive` 标签页，分组展示 25 个工具的动态表单、快捷查询按钮、JSON 结果区和后台任务面板。
- HTTP API 前缀 `/api/aliyundrive`：`GET /tools`、`POST /execute`、`GET /tasks`、`POST /tasks/stop`。
- 独立验收页 `/aliyundrive`：无需进入 DSH 会话即可直接打开完整控制台（同样由工具 schema 驱动 25 个工具表单）。
- `registerAliyundriveApi` 通过可选 `ctx.inject(['webServer'])` 等待 Web 服务，headless profile 中保持惰性。

### 6.4 输出解析
- `classifyResult`：所有工具识别「未登录账号」并归一化为 `NOT_LOGGED_IN`，附带 `aliyunpan_login` 引导；非零退出且无错误时归一化为 `CLI_ERROR`。
- 结构化结果包含：`ok`、`error`、`message`、`code`、`stdout`、`stderr`、`command`、`durationMs`；长任务额外返回 `taskId`。
- `pwd`/`ls`/`album_show` 在成功时补充 `path`/`files` 字段。
- `aliyunpan_task_status`/`aliyunpan_task_list` 对 running 任务附加快照 `progress`/`stdoutTail`；`aliyunpan_task_stop` 向进程发送停止信号。
