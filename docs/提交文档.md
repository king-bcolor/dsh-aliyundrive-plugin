# 阿里云盘命令行 DeepSeek Harness 插件 — 提交文档

## 1. 提交前检查
- [ ] 用例目录、用例文档说明、需求文档说明、UI 控件文档说明、实现文档已入库。
- [ ] TDD 测试全绿：`npm test`。
- [ ] 构建产物可加载：`npm pack --dry-run`。
- [ ] 本地验收：`dsh --profile aliyun-accept add .` 并 `--dump-config`。
- [ ] 中英文 README 开头互相引用。
- [ ] 无登录态/配置凭据入库。

## 2. gh 创建并推送仓库
```bash
cd dsh-aliyundrive-plugin
git init
git add .
git commit -m "test: add failing tests for aliyundrive plugin"
git commit -m "feat: implement aliyunpan tools for DeepSeek Harness"
gh repo create dsh-aliyundrive-plugin --public --source=. --remote=origin --push
```

## 3. 标签策略
### 3.1 同类插件标签调研
- 官方必加：`dsh-plugin`。
- 云盘/CLI 插件常见：`deepseek-harness`、`aliyundrive`、`aliyunpan`、`adrive`、`cloud-drive`、`cli`、`agent-tool`。
### 3.2 设置命令
```bash
gh repo edit king-bcolor/dsh-aliyundrive-plugin \
  --add-topic dsh-plugin \
  --add-topic deepseek-harness \
  --add-topic aliyundrive \
  --add-topic aliyunpan \
  --add-topic cloud-drive \
  --add-topic cli \
  --add-topic agent-tool
```

## 4. 用户集成方式
```bash
# GitHub 直装
dsh plugin --profile default add github:king-bcolor/dsh-aliyundrive-plugin
# 锁定 commit
dsh plugin --profile default add github:king-bcolor/dsh-aliyundrive-plugin#<sha>
# npm / tarball
npm publish
dsh plugin --profile default add dsh-aliyundrive-plugin
```
启动：`dsh --profile default`。

## 5. 发布清单
```bash
npm test
npm pack --dry-run
dsh plugin --profile aliyun-accept add .
dsh --profile aliyun-accept --dump-config
git tag v0.1.0 && git push origin v0.1.0
gh release create v0.1.0 --generate-notes
```
